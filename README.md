# autoprobe - `autoconf`-style configuration probing in `build2`

This project shows how to implement `autoconf` (and CMake/Meson/etc)-style
configuration probing in `build2`. See the [How do I implement
`autoconf`-style configuration
probing?](https://github.com/build2/HOWTO/blob/master/entries/implement-configuration-probing.md)
HOWTO article for details.
